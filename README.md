# Dronefire

A fast stylised FPS with vehicles, aircraft and swords, built in Zig with raylib for Linux and Android.

## Build

```
zig build -Drelease
./zig-out/bin/dronefire
```

Android: `zig build -Dandroid -Drelease` writes `zig-out/dronefire.apk`.
